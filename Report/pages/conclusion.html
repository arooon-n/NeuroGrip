Conclusion and Future Work

Conclusion

We developed a brain-controlled robotic arm using EEG signals from OpenBCI channels. A robust preprocessing pipeline (bandpass filtering, ICA, CAR) enhanced signal quality. Frequency-domain features were extracted and used to train a custom CNN-BiLSTM (MDCBN) model, which effectively decoded motor imagery for real-time arm control. This project demonstrates the potential of non-invasive EEG in assistive robotics and neurorehabilitation applications.

Future Enhancements

While our system demonstrates significant capabilities, several areas for future research and development have been identified:

  • Real-time implementation and optimization techniques which could improve the model interference speed for smoother arm control
  • Expanding it to support multiclass classification (e.g., left/right/up/down) or continuous control using regression models or reinforcement learning could make the system more versatile.
  • Integrating transfer learning or adaptive models can enhance generalization and reduce the need for extensive retraining for each new user.
  • Hybrid BCI Systems: Combining EEG with other biosignals like EMG (muscle signals) or EOG (eye movements) may create more robust hybrid systems, reducing ambiguity in command classification.
