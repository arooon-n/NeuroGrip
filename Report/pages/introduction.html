Introduction

NeuroGrip is an advanced EEG-based brain-machine interface (BMI) system designed to control a robotic arm using intuitive motor imagery. Inspired by the paper Brain-Controlled Robotic Arm System Based on Multi-Directional CNN-BiLSTM Network Using EEG Signals, this project leverages deep learning techniques to decode EEG signals and translate them into real-time robotic arm movements. In addition to EEG-based system, it implements Robotic Arm movements based on voice commands.
